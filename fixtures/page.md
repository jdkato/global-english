# Getting started

Setting up the agent is a piece of cake, and it's the low-hanging fruit for most teams. Don't drop the ball on the rest.

## Install

To setup the agent, download the package via the CLI, e.g., with Homebrew, etc. Since the installer is signed, you can skip the checksum.

Ensure the service is running. It writes its logs to the default folder. This means you may need to find out where the folder is.

## Configure

Open the user account settings page, and turn off the old proxy. The CLI is fast, while the API is flexible. As the token is shared, rotate it monthly.

Folks, this awesome tool is gonna save you tons of time (no pun intended).

When you have finished the installation and confirmed that the agent starts, open the dashboard, choose the project you want to connect, and paste the token you copied earlier into the field at the bottom.
