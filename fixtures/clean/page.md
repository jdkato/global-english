# Getting started

Installing the agent is easy, and it is the first improvement for most teams. Complete the other steps carefully.

## Install

To set up the agent, download the package through the CLI. For example, use Homebrew. The installer is signed, so you can skip the checksum.

Ensure that the service is running. The service writes its logs to the default folder. You might need to learn where the folder is.

## Configure

Open the settings page for your account, and disable the old proxy. The CLI is fast, whereas the API is flexible. The token is shared, so rotate it monthly.

This tool saves people a lot of time.

When the agent starts, open the dashboard. Choose the project to connect. Then paste the token into the field at the bottom.
